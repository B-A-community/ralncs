RALNCS 1.0 — quick guide

SketchUp 2024 extension: RAL Classic and NCS 1950 color fan, nearest RAL/NCS for every model material, one-click color spec

1Install

SketchUp → Window → Extension Manager → Install Extension → pick RALNCS-1.0-eng.rbz → restart SketchUp. You get the “RALNCS” toolbar (two buttons) and the Extensions → RALNCS menu.

2RAL / NCS fan

“Fan” toolbar button or Extensions → RALNCS → RAL / NCS fan.

  1. Tab RAL Classic (216 colors) or NCS 1950 (1950 colors). Search by code or name: 3020, traffic, 0580-Y80R.
  2. Click a color — a large swatch, code, HEX and RGB appear on the right.
  3. Create material — a material named RAL 3020 Traffic red is added to the model.
    Create and paint — same, plus the Paint Bucket tool is activated.

On-screen colors are sRGB approximations. Monitors differ: verify the final choice against a physical fan deck.

3Material audit (spec)

“Audit” toolbar button or Extensions → RALNCS → Material audit (spec). The plugin takes all model materials (textured ones use the averaged texture color and are tagged “texture”) and finds the nearest RAL and NCS for each.

The ΔE column shows how far the match is from the original color: <1 excellent  <2 good  <5 noticeable  ≥5 outside the palette.

  • Columns ▾ — show/hide and reorder columns; the RAL and NCS groups can be hidden or swapped as a whole. The setup is remembered.
  • Copy spec — exactly the columns on screen go to the clipboard. In Google Sheets / Excel press Ctrl+V: the “Color” columns paste with real cell fills, RGB comes in spec format (240-211-208).
  • Apply RAL / Apply NCS — recolor the checked materials to the exact palette color. Undo with Ctrl+Z.
  • tint textured — off by default: textures are left untouched. Turn it on to have SketchUp tint the texture to the palette color.
Known limitation. With Enscape 4.1 loaded, undoing (Ctrl+Z) a texture tint may close SketchUp — this is an Enscape bug. Save the model before bulk tinting; updating Enscape helps.
