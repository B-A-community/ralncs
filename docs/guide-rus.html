RALNCS 1.0 — краткая инструкция

Плагин SketchUp 2024: веер RAL Classic и NCS 1950, подбор ближайших RAL/NCS для материалов модели, ТЗ в один клик

1Установка

SketchUp → Window → Extension Manager → Install Extension → выбрать RALNCS-1.0-rus.rbz → перезапустить SketchUp. Появится панель инструментов «RALNCS» (две кнопки) и меню Extensions → RALNCS.

2Веер RAL / NCS

Кнопка «Веер» на панели или Extensions → RALNCS → Веер RAL / NCS.

  1. Вкладка RAL Classic (216 цветов) или NCS 1950 (1950 цветов). Поиск по коду или названию: 3020, traffic, 0580-Y80R.
  2. Клик по цвету — справа крупный образец, код, HEX и RGB.
  3. Создать материал — материал RAL 3020 Traffic red появится в модели.
    Создать и красить — то же плюс сразу инструмент «Заливка».

Цвета на экране — sRGB-приближение. Мониторы передают цвет по-разному: финальное решение сверяйте с физическим веером.

3Анализ материалов (ТЗ)

Кнопка «Анализ» на панели или Extensions → RALNCS → Анализ материалов (ТЗ). Плагин берёт все материалы модели (у текстурных — усреднённый цвет текстуры, метка «текстура») и для каждого находит ближайший RAL и NCS.

Столбец ΔE — насколько подобранный цвет отличается от исходного: <1 отлично  <2 хорошо  <5 заметно  ≥5 цвет вне палитры.

  • Столбцы ▾ — включить/выключить столбцы, поменять порядок; группы RAL и NCS можно скрыть или переставить целиком. Настройка запоминается.
  • Скопировать ТЗ — в буфер уходят ровно те столбцы, что на экране. В Google Таблице / Excel нажмите Ctrl+V: колонки «Цвет» вставятся с реальной заливкой, RGB — в формате ТЗ (240-211-208).
  • Применить RAL / Применить NCS — перекрасить выбранные галочками материалы в точный цвет палитры. Отмена — Ctrl+Z.
  • тонировать текстурные — по умолчанию выключено: текстуры не трогаются. Включите, чтобы SketchUp затонировал текстуру в цвет палитры.
Известное ограничение. При загруженном Enscape 4.1 откат (Ctrl+Z) тонирования текстур может закрыть SketchUp — это ошибка Enscape. Перед массовым тонированием сохраните модель; помогает обновление Enscape.
