# RALNCS — RAL / NCS extension for SketchUp 2024

[Русский](README.md) · **English**

A “RALNCS” toolbar (two buttons; shown on first launch, then remembers its
state) plus the same commands under `Extensions → RALNCS`.

Two features (plus “About…” in the menu — authors, version, repository link):

1. **RAL / NCS fan** (`Extensions → RALNCS → RAL / NCS fan`) — a browser for
   RAL Classic (216 colors) and NCS 1950 (the standard collection, 1950 colors)
   with sRGB screen equivalents. Click a color → “Create material” or
   “Create and paint” (the Paint Bucket tool is activated right away).
2. **Material audit (spec)** (`Extensions → RALNCS → Material audit (spec)`) —
   scans **all** model materials: solid ones use their fill color, textured
   ones use the averaged texture color (computed by SketchUp itself) and are
   tagged “texture”. For each material it finds the nearest RAL and NCS by
   CIEDE2000 (ΔE) and shows a table:
   - “Columns” — which columns to show and in what order; the RAL and NCS
     groups can be hidden or swapped as a whole. The setup is remembered.
   - “Copy spec” — **exactly the columns on screen** go to the clipboard in
     two formats at once: TSV (text) and HTML with cell fills. Google Sheets /
     Excel split them into columns on Ctrl+V and **fill the “Color” columns**
     with real colors (original, RAL, NCS). RGB is also given in facade-spec
     format (`240-211-208`);
   - “Apply RAL / NCS” — recolors the selected materials to the exact palette
     color. Textured materials are skipped by default; with “tint textured”
     checked, SketchUp tints the texture to the palette color. Undo with
     Ctrl+Z. Materials are never renamed.

ΔE scale (CIEDE2000): `<1` — excellent, `<2` — good, `<5` — noticeable
difference, `≥5` — outside the palette.

## Known limitations

- **Enscape 4.1 + texture tinting + Ctrl+Z may crash SketchUp.** When the
  tint is undone SketchUp deletes its internal texture copy, and the Enscape
  observer (`Enscape.RubyApi` 4.1.0.1388) touches an already-freed object —
  `AccessViolationException` in `coreclr.dll`, SketchUp closes entirely. This
  is an Enscape bug and cannot be worked around from the extension. Save the
  model before bulk tinting; updating Enscape helps.

## Download and install

Release **1.0**: [release page](https://github.com/B-A-community/ralncs/releases/tag/v1.0).

| | Russian UI | English UI |
|---|---|---|
| Extension + guide (zip) | [RALNCS-1.0-rus.zip](https://github.com/B-A-community/ralncs/releases/download/v1.0/RALNCS-1.0-rus.zip) | [RALNCS-1.0-eng.zip](https://github.com/B-A-community/ralncs/releases/download/v1.0/RALNCS-1.0-eng.zip) |
| Extension only (rbz) | [RALNCS-1.0-rus.rbz](https://github.com/B-A-community/ralncs/releases/download/v1.0/RALNCS-1.0-rus.rbz) | [RALNCS-1.0-eng.rbz](https://github.com/B-A-community/ralncs/releases/download/v1.0/RALNCS-1.0-eng.rbz) |
| Guide (PDF) | [guide-rus.pdf](https://github.com/B-A-community/ralncs/releases/download/v1.0/RALNCS-1.0-guide-rus.pdf) | [guide-eng.pdf](https://github.com/B-A-community/ralncs/releases/download/v1.0/RALNCS-1.0-guide-eng.pdf) |

Install: SketchUp → `Window → Extension Manager → Install Extension` → pick
the `.rbz` → restart SketchUp.

Both builds come from the same source and differ only in UI language: every
string lives in `src/ralncs/lang.rb` (Ruby) and `src/ralncs/html/i18n.js`
(dialogs); the build script swaps the `LANG = 'ru'|'en'` line in a copy.

- Build: `.\build.ps1` (both languages) or `.\build.ps1 -Lang en` →
  `dist\RALNCS-<version>-rus|eng.rbz`.
- Development: `.\dev_install.ps1` copies `src\` (Russian) into the SketchUp
  2024 Plugins folder; `tools\su_exec.ps1` runs Ruby inside a running SketchUp.

## Layout

```
src/
  ralncs.rb              extension registration
  ralncs/
    main.rb              menu and toolbar
    lang.rb              Ruby-side strings (ru/en)
    about.rb             “About” dialog
    color_math.rb        sRGB→Lab (D65), CIEDE2000
    palette.rb           palette loading, nearest-color search
    audit.rb             material audit + applying colors
    fan.rb               fan, material creation
    data/*.json          palettes (generated by tools/build_data.ps1)
    html/*.html          UI (UI::HtmlDialog)
    html/i18n.js         dialog strings (ru/en)
design/                  design code shared by all B&A extensions (CSS, JS, template, icons)
docs/                    quick guides (html → pdf)
tools/build_data.ps1     generates data/*.json from open datasets
tools/su_exec.ps1        runs Ruby inside a running SketchUp via sketchup_mcp_server
```

## Data sources and caveats

- RAL Classic: [gist lunohodov/1995178](https://gist.github.com/lunohodov/1995178).
- NCS 1950: collection 263 from [5monkeys/python-ncs](https://github.com/5monkeys/python-ncs).
- All values are **sRGB approximations** for the screen. RAL and NCS are
  physical color systems; verify exact matches against a physical fan deck.
  NCS is a trademark of NCS Colour AB; treat the values as “approximate NCS
  notations”.
