# Дизайн-код плагинов B&A — переносимый набор

Скопируй папку `design/` в другой плагин — и его окна будут выглядеть как RALNCS.

```
design/
  designcode.md      правила: принципы, палитра, типографика, паттерны, тексты
  ba.css             общий стиль всех компонентов (кнопки, таблицы, свотчи, бейджи, попап, тост)
  ba.js              хелперы: тост, confirm с Ctrl+Z, буфер TSV+HTML, попап, чекбокс «все», цвета
  template.html      стартовое окно: шапка → статус → таблица → футер, уже на ba.css/ba.js
  icons/             fan.svg, audit.svg — образцы; _template.svg — заготовка с палитрой в комментарии
  snippets/
    toolbar.rb       панель инструментов + меню с SVG-иконками
    dialog.rb        HtmlDialog: ready → init(json), одна undo-операция, настройки в реестре
```

## Как применить к плагину

1. `ba.css`, `ba.js` → в папку `html/` плагина рядом с его html-файлами.
2. Новое окно — копия `template.html`, переименовать, заменить колонки и действия.
   Старое окно — подключить `ba.css` вместо своих стилей и пройтись по
   `designcode.md` (одна акцентная кнопка, статусная строка, тост вместо alert).
3. Иконки — по `icons/_template.svg`, палитра и толщина обводки внутри.
4. Ruby — по `snippets/`: тулбар с `get_last_state`, диалог с `ready`/`execute_script`.

Полный набор правил и «почему» — в [designcode.md](designcode.md).
