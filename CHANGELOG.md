# Журнал изменений

Формат: что изменилось и почему. Версия расширения задаётся в
`src/ralncs.rb`, оттуда же её берёт сборщик пакета (`build.ps1`).

## 1.0 — релиз

Два пакета из одного исходника: `RALNCS-1.0-rus.rbz` и `RALNCS-1.0-eng.rbz`.

- **Английская версия.** Все надписи вынесены в словари: `lang.rb` (меню,
  заголовки окон, сообщения, имена undo-операций) и `html/i18n.js` (три окна).
  Разметка держит русский текст как запасной, `applyLang()` переводит на месте
  по `data-t`; строки с числами — через `tf()` с `{плейсхолдерами}`. Язык
  выбирается одной строкой `LANG`, которую `build.ps1 -Lang` подменяет в копии
  исходников. Логика и дизайн не менялись; проверено, что русская версия
  слово в слово совпадает с 0.4.
- Краткие инструкции на одну страницу: `docs/RALNCS-1.0-guide-rus.pdf` и
  `-eng.pdf` (html в `docs/`, печать headless Chrome).
- Версия расширения — `1.0`; окно «О плагине» показывает её автоматически.

## 0.4 — тестовая сборка

Правки коллеги после прогона 0.3:

- Пункт меню «О плагине…»: маленькое окно с авторами (Ruslan Tkachenko и
  Maksar Sanjeev), версией и ссылкой на репозиторий — ссылка открывается
  в системном браузере через `UI.openURL`.
- **Настраиваемые столбцы** (кнопка «Столбцы»): любой столбец можно
  скрыть или передвинуть, группы RAL и NCS — скрыть или поменять местами
  целиком одним кликом («если RAL совсем не нужен — прячешь»). Экранная
  таблица и буфер обмена строятся из одного списка, поэтому «копировать
  только нужные столбцы» получается само собой. Настройка запоминается
  в реестре SketchUp (компактной строкой — `write_default` плохо
  переживает JSON с кавычками).
- **Тонирование текстур — опция.** В 0.3 текстурные при перекраске всегда
  пропускались; коллеге нужно, чтобы текстура тонировалась. Галочка
  «тонировать текстурные» (по умолчанию выключена): с ней «Применить»
  красит и текстурные, SketchUp тонирует текстуру в цвет палитры.
  Подтверждение говорит, сколько текстур будет затонировано.
- Шапка таблицы стала двухуровневой (группа → столбец), чтобы при
  перестановке групп было видно, где чьи столбцы.

Проверка в живом SketchUp на реальной модели (1211 материалов, из них 474
текстурных, Enscape загружен):

- **Скан ускорен с 9,2 до 1,05 с.** Два приёма: подбор кэшируется по hex
  (в модели 763 уникальных цвета на 1211 материалов), а точный CIEDE2000
  считается только среди 40 кандидатов по дешёвому CIE76. Для цветов далеко
  за пределами палитры (ΔE > 8) CIE76 и CIEDE2000 расходятся — такие
  досчитываются полным перебором. На всех 763 цветах результат совпал
  с честным минимумом CIEDE2000 (0 расхождений).
- Пока идёт расчёт, статусная строка показывает «Считаю…», а не пустоту.
- Настройка столбцов, перекраска без/с тонированием и откат Ctrl+Z
  проверены на реальном материале — работают.
- Найдено падение SketchUp при откате тонирования с загруженным Enscape 4.1
  (`AccessViolationException` в наблюдателе Enscape) — ошибка Enscape,
  зафиксирована в README как известное ограничение.
- В `tools/su_exec.ps1` — запуск Ruby в работающем SketchUp через наш
  `sketchup_mcp_server` (порт 8080), чтобы гонять проверки без перезапуска.

## 0.3 — тестовая сборка

Правки по итогам прогона на реальной модели (119 однотонных / 83 текстурных):

- **Текстурные материалы больше не пропускаются.** Решение «только однотонные»
  из 0.1 отменено: на живом проекте за бортом оставалась половина фасада
  (кирпич, дерево). Цветом текстурного материала считается усреднённый цвет
  текстуры — его отдаёт сам SketchUp (`Material#color`); в таблице такие
  строки помечены «текстура».
- Перекраска по-прежнему только для однотонных: у текстурного `color=`
  затонировал бы саму текстуру. Кнопки «Применить» отбрасывают текстурные
  и говорят об этом в подтверждении.
- **Переименование убрано совсем** (в 0.1–0.2 было опцией): по опыту
  неудобно, ТЗ-таблички достаточно.
- В выгрузке новые колонки: «Тип» (заливка/текстура) и RGB в формате ТЗ
  на фасады (`240-211-208`) — для исходного цвета, RAL и NCS.

## 0.2 — тестовая сборка

**Релиза нет, пакет для установки не выкладывается.** Собирается локально
(`build.ps1`) под именем `RALNCS_0.2.0.rbz` и раздаётся напрямую на время
проверки.

- Панель инструментов с двумя кнопками и SVG-иконками; при первой загрузке
  показывается сама, дальше SketchUp запоминает её состояние. Команды
  продублированы в меню `Extensions → RALNCS`.
- В выгрузке ТЗ появились колонки «Цвет» (исходный, RAL, NCS). Буфер обмена
  заполняется двумя форматами сразу — TSV и HTML с заливкой ячеек, поэтому
  Google Таблицы и Excel при обычной вставке закрашивают эти колонки
  реальными цветами. Вставка «только значения» заливку не переносит —
  ограничение самих таблиц.

## 0.1

Исходный прототип, две функции:

- **Веер RAL / NCS**: браузер палитр RAL Classic (216) и NCS 1950 (полный
  стандартный веер) с sRGB-эквивалентами для экрана, поиском и созданием
  материала в один клик (опционально сразу с инструментом «Заливка»).
- **Анализ материалов (ТЗ)**: для каждого однотонного материала модели
  подбираются ближайшие RAL и NCS (sRGB → Lab D65 + CIEDE2000, формула
  проверена на эталонных парах Шармы — `test/ciede_test.html`), таблица
  копируется в буфер для Google Таблиц, выбранные материалы можно
  перекрасить в точные цвета палитры с отменой по Ctrl+Z.
- Текстурные материалы сознательно пропускаются — анализируются только
  однотонные заливки.
- Данные палитр генерируются из открытых датасетов (`tools/build_data.ps1`);
  NCS — товарный знак NCS Colour AB, значения храним как приближённые.
