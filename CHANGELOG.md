## 0.3 — тестовая сборка

Правки по итогам прогона на реальной модели (119 однотонных / 83 текстурных):

- **Текстурные материалы больше не пропускаются.** Решение «только однотонные»
  из 0.1 отменено: на живом проекте за бортом оставалась половина фасада
  (кирпич, дерево). Цветом текстурного материала считается усреднённый цвет
  текстуры — его отдаёт сам SketchUp (`Material#color`); в таблице такие
  строки помечены «текстура».
- Перекраска по-прежнему только для однотонных: у текстурного `color=`
  затонировал бы саму текстуру. Кнопки «Применить» отбрасывают текстурные
  и говорят об этом в подтверждении.
- **Переименование убрано совсем** (в 0.1–0.2 было опцией): по опыту
  неудобно, ТЗ-таблички достаточно.
- В выгрузке новые колонки: «Тип» (заливка/текстура) и RGB в формате ТЗ
  на фасады (`240-211-208`) — для исходного цвета, RAL и NCS.

## 0.2 — тестовая сборка

**Релиза нет, пакет для установки не выкладывается.** Собирается локально
(`build.ps1`) под именем `RALNCS_0.2.0.rbz` и раздаётся напрямую на время
проверки.

- Панель инструментов с двумя кнопками и SVG-иконками; при первой загрузке
  показывается сама, дальше SketchUp запоминает её состояние. Команды
  продублированы в меню `Extensions → RALNCS`.
- В выгрузке ТЗ появились колонки «Цвет» (исходный, RAL, NCS). Буфер обмена
  заполняется двумя форматами сразу — TSV и HTML с заливкой ячеек, поэтому
  Google Таблицы и Excel при обычной вставке закрашивают эти колонки
  реальными цветами. Вставка «только значения» заливку не переносит —
  ограничение самих таблиц.

## 0.1

Исходный прототип, две функции:

- **Веер RAL / NCS**: браузер палитр RAL Classic (216) и NCS 1950 (полный
  стандартный веер) с sRGB-эквивалентами для экрана, поиском и созданием
  материала в один клик (опционально сразу с инструментом «Заливка»).
- **Анализ материалов (ТЗ)**: для каждого однотонного материала модели
  подбираются ближайшие RAL и NCS (sRGB → Lab D65 + CIEDE2000, формула
  проверена на эталонных парах Шармы — `test/ciede_test.html`), таблица
  копируется в буфер для Google Таблиц, выбранные материалы можно
  перекрасить в точные цвета палитры с отменой по Ctrl+Z.
- Текстурные материалы сознательно пропускаются — анализируются только
  однотонные заливки.
- Данные палитр генерируются из открытых датасетов (`tools/build_data.ps1`);
  NCS — товарный знак NCS Colour AB, значения храним как приближённые.
