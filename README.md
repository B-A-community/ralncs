# RALNCS — плагин RAL / NCS для SketchUp 2024

Панель инструментов «RALNCS» (две кнопки, показывается при первом запуске,
дальше запоминает состояние) + то же в меню `Extensions → RALNCS`.

Две функции (плюс «О плагине…» в меню — авторы, версия, ссылка на репозиторий):

1. **Веер RAL / NCS** (`Extensions → RALNCS → Веер RAL / NCS`) — браузер палитр
   RAL Classic (216 цветов) и NCS 1950 (стандартная коллекция, 1950 цветов) с
   sRGB-эквивалентами для экрана. Клик по цвету → «Создать материал» или
   «Создать и красить» (сразу активируется заливка).
2. **Анализ материалов (ТЗ)** (`Extensions → RALNCS → Анализ материалов (ТЗ)`) —
   сканирует **все** материалы модели: у однотонных берётся цвет заливки, у
   текстурных — усреднённый цвет текстуры (его считает сам SketchUp), такие
   строки помечаются «текстура». Для каждого находит ближайший RAL и NCS по
   CIEDE2000 (ΔE) и показывает таблицу:
   - «Столбцы» — какие столбцы показывать и в каком порядке; группы RAL и
     NCS можно скрыть или поменять местами целиком. Настройка запоминается.
   - «Скопировать ТЗ» — в буфер уходят **ровно те столбцы, что на экране**,
     в двух форматах сразу: TSV (текст) и HTML с заливкой ячеек. Google
     Таблицы / Excel при Ctrl+V раскладывают по колонкам и **закрашивают
     колонки «Цвет»** реальными цветами (исходный, RAL, NCS). RGB есть и в
     формате ТЗ на фасады (`240-211-208`);
   - «Применить RAL / NCS» — перекрашивает выбранные материалы в точный цвет
     палитры. Текстурные по умолчанию пропускаются; с галочкой «тонировать
     текстурные» SketchUp тонирует текстуру в цвет палитры. Отменяется через
     Ctrl+Z. Материалы не переименовываются.

Шкала ΔE (CIEDE2000): `<1` — отлично, `<2` — хорошо, `<5` — заметная разница,
`≥5` — цвет вне палитры.

## Известные ограничения

- **Enscape 4.1 + тонирование текстур + Ctrl+Z может уронить SketchUp.**
  При откате тонирования SketchUp удаляет внутреннюю копию текстуры, а
  наблюдатель Enscape (`Enscape.RubyApi` 4.1.0.1388) обращается к уже
  освобождённому объекту — `AccessViolationException` в `coreclr.dll`,
  SketchUp закрывается целиком. Ошибка в Enscape, из плагина не обходится.
  Перед массовым тонированием сохраните модель; помогает обновление Enscape.

## Установка

**Релиза нет, готовый `.rbz` не выкладывается** — сборка локальная, пакет
раздаётся напрямую на время проверки.

- Сборка: `.\build.ps1` → `dist\RALNCS_<версия>.rbz`, затем в SketchUp:
  `Window → Extension Manager → Install Extension`.
- Для разработки: `.\dev_install.ps1` копирует `src\` в папку Plugins SketchUp 2024.

## Структура

```
src/
  ralncs.rb              регистрация расширения
  ralncs/
    main.rb              меню
    color_math.rb        sRGB→Lab (D65), CIEDE2000
    palette.rb           загрузка палитр, поиск ближайшего цвета
    audit.rb             анализ материалов + применение цветов
    fan.rb               веер, создание материалов
    data/*.json          палитры (генерируются tools/build_data.ps1)
    html/*.html          интерфейс (UI::HtmlDialog)
tools/build_data.ps1     генерация data/*.json из открытых датасетов
```

## Источники данных и оговорки

- RAL Classic: [gist lunohodov/1995178](https://gist.github.com/lunohodov/1995178).
- NCS 1950: коллекция 263 из [5monkeys/python-ncs](https://github.com/5monkeys/python-ncs).
- Все значения — **sRGB-приближения** для экрана. RAL и NCS — физические системы
  цвета; точное соответствие проверяется по физическому вееру. NCS — товарный знак
  NCS Colour AB; при публикации плагина формулировать как «approximate NCS notations».
